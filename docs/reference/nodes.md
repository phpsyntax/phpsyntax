# Nodes

Generated by `composer reference` from grammar/nodes.php and the node classes; do not edit. 119 node classes under `PhpSyntax\Nodes`; a slot type is `Token`, a node class, `?` when optional, `A|B` for a choice, `NodeList<T>` or `SeparatedNodeList<T>` for a list. The layout role is what the slot is to the indentation of the lines the node spreads over (`PhpSyntax\LayoutRole`).
